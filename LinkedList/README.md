# Linked List
메모리 구조상 떨어져 있는 곳에 존재하는 데이터를 연결하여 관리하는 방식으로 데이터를 저장하는 자료구조이다.

배열과 달리 데이터를 저장하는 공간과 다음 데이터의 주소를 저장하는 공간이 분리되어 있다.

Array는 데이터를 추가하거나 삭제할 때 데이터를 옮겨야 하지만, Linked List는 데이터를 추가하거나 삭제할 때 다음 데이터의 주소만 변경하면 된다.

공간의 최대 크기를 미리 정하지 않아도 되며, 데이터를 동적으로 관리할 수 있다는 장점이 있다.

## Singly Linked List
단방향으로 연결되어 있는 Linked List이다.

각 노드는 데이터와 다음 노드의 주소를 가지고 있다. 다음 노드는 이전 노드의 주소를 알지 못한다.

## Doubly Linked List
양방향으로 연결되어 있는 Linked List이다.

각 노드는 데이터와 다음 노드의 주소, 이전 노드의 주소를 가지고 있다.
